# Portafolio de Diseño Web · Examen Parcial

Sitio web responsivo Diseño Web

## Descripción
 secciones *Sobre mí*, *Proyectos*, *Multimedia* y *Contacto*.

## Tecnologías utilizadas
- **HTML5** semántico (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3**: selectores `id` y `class`, cajas flotantes (`float` y `clear`), `transition`, `transform`, `@keyframes` y `@media` queries
- **Multimedia**: audio local (`<audio>`) e `<iframe>` de YouTube
- **SEO básico**: `title`, `description`, `keywords`, `viewport` y atributos `alt`
- **GitHub Pages** para la publicación
